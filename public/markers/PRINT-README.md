# 列印 ArUco B

優先列印 `aruco-board-A4-55mm-ids0-3.pdf`：A4 直式、100%／實際大小，關閉符合頁面。四個黑色正方形外緣都是 55 mm，白邊不計。列印後用尺確認 55 mm 和底部 50 mm 檢查線。

- 整張不裁切、不重排：可使用附上的固定版面 JSON，中心間隔水平／垂直都是 90 mm。
- 裁開貼到螢幕左右：保留至少約 10 mm 白邊，固定平整；必須重新量測每張的相對位置與方向，原 JSON 便不適用。
- 各別 PNG 適合螢幕顯示或自行排版；列印軟體可能忽略 PNG 尺寸，不要用 PNG 的螢幕大小當公尺尺度。
- ID 0～3 互不相同。不要把兩張 ID 0 同時放入相機視野；原手機 ID 0 請收起或換成另一個 ID。
- `camera_preview.py --board aruco-board-A4-55mm-ids0-3.json` 可啟用共同定位；未提供 --board 時仍只用 ID 0。JSON 座標會依 --marker-m 與設計尺寸比例換算，所以整張需保持原排列並等比例列印。

多標記可提供更多可見角點與遮擋容錯，不能擴大鏡頭本身的視角，也無法消除所有平面 PnP 歧義、動態模糊與未校正誤差。
