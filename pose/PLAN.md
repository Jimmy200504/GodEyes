# 單一 ArUco B demo plan

固定方案：Logitech webcam 綁頭朝外、無 IMU；螢幕旁固定一個已知尺寸的 B。CPU 執行 ArUco + PnP，傳 pose 到渲染電腦。不需要 A、SLAM 或 NPU。

1. 使用固定 ID 0 的 B；目前手機顯示的黑色正方形外緣邊長為使用者量得的 5.5 cm（0.055 m），已設為傳送器預設。
2. 用同一解析度、固定焦距拍棋盤格，求相機內參與畸變。
3. 只偵測指定 ID，以 IPPE square 解 PnP、檢查正深度與重投影誤差，再反轉成 c2w。
4. 透過現有 API 傳位置（公尺）與 quaternion；看不到 tag 傳 lost，斷線後重試，只保留最新結果。
5. 合成影像與已知投影測試通過後，真機檢查各軸方向、已知距離、遮擋、延遲與抖動。

軟體實作與自動測試在此 worktree 完成；實體列印、校正與真機驗收需要使用者的 webcam／板子。多標記板與濾波等實測後再加。
